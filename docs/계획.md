# 작업 계획과 결과

1. ROM 구조 분석: 텍스트는 `Localization/str_JPN.STR`(STBL)과 이름 txt 8종, 폰트는 `Arial14.nftr`(루트·font/ 2종, SJIS 직접 매핑 1bpp). ARM9·오버레이에는 표시 문자열 없음. → 완료
2. 폰트 선정: 원본 한자 11×11 도트 → 갈무리11 네이티브 11×11 채택(갈무리 우선, 나눔스퀘어 네오·서울한강보다 원본과 유사). → 완료
3. POC: 메뉴 몇 개만 바꿔 헤드리스 에뮬레이터로 표시·줄바꿈 확인. → 완료
4. 용어집(`translation/glossary.md`) 작성 후 고유 문장 8,683개를 32묶음으로 나눠 직접 번역, 묶음별 검증기(`tools/check.py`)로 변수·공백·인코딩·일본어 잔존 0 확인. → 완료
5. 이름 파일 8종 직접 번역(`tools/txt_src.py`). → 완료
6. 빌드·에뮬레이터 확인·xdelta(`-0 -S none`) 생성과 왕복 해시 확인. → 완료
7. 전수검사: 빌드 ROM 텍스트 재검사(`tools/verify.py`), 그래픽 869개 렌더링 검사(`tools/render_gfx.py`). 잔존 2건(반각 점 1건, 배너 제목) 수정. → 완료
